# 社交网络视角下上海核心区奶茶品牌选址分析

用社交网络分析方法量化上海黄浦、静安核心区奶茶品牌的竞争格局与选址逻辑，面向「本地生活 / 商业分析」方向。

## 业务问题

- 上海核心区奶茶品牌的竞争格局是怎样的？
- 品牌之间是否存在「跟随开店」策略？哪些位置竞争最激烈？
- 新品牌 / 新门店应如何选择商圈与渠道（商场店 vs 街边店）？

## 数据来源

- 团队采集：10 个主流品牌、190 家门店，字段含品牌、商圈、是否商场店、经纬度等。
- 个人贡献：思路设计、代码实现、报告撰写（其余成员负责数据采集与整理）。

## 分析方法

- 以「商圈共现」构建品牌竞争网络（networkx）。
- 中心性指标：加权度、介数、接近中心性、集聚系数、Katz、特征向量。
- 社区发现与模块度；Jaccard 相似度刻画品牌跟随关系。
- 经纬度 + Haversine 距离计算 500 米半径内竞争密度。

## 关键发现

- 总网络模块度为 0，商圈筛选后仅 0.02：品牌选址高度趋同、全面竞争。
- 霸王茶姬与喜茶选址相似度高达 0.75，存在明显的「贴身跟随」策略。
- 品牌可聚类为「购物中心集群」与「街边 / 地铁集群」。
- 茉莉奶白、爷爷不泡茶集中在竞争高压区；霸王茶姬布局广阔，加权度高且平均竞争密度低。

## 业务建议

- 新品牌可优先错位进入竞争密度较低、但客流可达的次级商圈。
- 跟随策略适合借势截流，但需评估同质化风险与租金成本。
- 商场店与街边店面向不同客群，渠道组合应与品牌定位匹配。

## 局限性

- 仅覆盖黄浦、静安两区，不能代表全上海及郊区。
- 数据采集存在主观筛选；7 家门店因经纬度缺失被剔除。
- 未纳入租金、人流量、销售额等经济指标。
