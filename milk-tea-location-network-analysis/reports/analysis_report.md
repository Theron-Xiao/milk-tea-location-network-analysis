# 社交网络视角下上海核心区奶茶品牌选址分析报告

## 1. 研究背景

现制茶饮竞争白热化，头部品牌在核心商圈高度集聚。本研究跳出单纯的门店数量统计，用社交网络方法量化品牌间的竞争与跟随关系。

## 2. 数据与模型

- 样本：上海黄浦、静安 10 个主流品牌、190 家门店，覆盖 31 个商圈。
- 51% 为购物中心门店，49% 为街边店；空间分析剔除 7 家经纬度缺失门店。
- 网络构建：品牌为节点，若两品牌出现在同一商圈则连边，共同出现次数为权重。

## 3. 网络拓扑分析

- 霸王茶姬（加权度 95）与喜茶（93）是绝对枢纽，覆盖几乎所有热门商圈。
- 各品牌 Katz 中心性接近，市场结构稳定，无孤立品牌。
- 集聚系数 0.4–0.6，竞争呈「对手的对手也是我的对手」的高集聚特征。
- 仅霸王茶姬、一点点具有明显介数，承担跨圈层连接；霸王茶姬接近中心性最高（10.03），触达竞争受众效率最高。

## 4. 跟随策略与集群

- 霸王茶姬与喜茶选址相似度 0.75，呈显著跟随关系。
- 基于商场 / 街边维度可分成两个集群：
  - 购物中心集群：霸王茶姬、喜茶、茉莉奶白、乐乐茶。
  - 街边 / 地铁集群：一点点、茶百道、蜜雪冰城、沪上阿姨。

## 5. 空间竞争密度

- 茉莉奶白（平均 6.38 竞品）、爷爷不泡茶（6.08）处于高压区。
- 霸王茶姬门店多但平均竞争密度仅 3.90，布局更广、错位更明显。

## 6. 结论与建议

核心区奶茶市场是一个无孤岛的致密网络，品牌选址本质是参与高水平竞争的「群舞」，通过集聚形成共生效应。新进入者应结合品牌定位，在「跟随截流」与「错位布局」间权衡，并区分商场与街边渠道。
